# Epics

## #start_here

New to Pivotal? Start with these cards. They teach the board itself — open one to read its note, drag one to a new lane, and try filtering. Safe to experiment; the demo resets on redeploy.

color: F2994A

## #board

The Kanban board you're looking at: four lanes, drag-and-drop between and within them, epic filters in the header, search, and dark mode. This whole app was planned and built on this board — the cards below are that work.

color: 3977E9

## #agent_api

The plain-HTTP API that lets an AI agent (Claude Code, Codex, …) read the board, add stories, move cards, and attach notes — the same board a human sees. Documented in skill.md.

color: 8E6CEF

## #portfolio

Grouping epics into higher-level initiatives. Open the Portfolios page to see these epics rolled up into the initiatives that ship Pivotal.
