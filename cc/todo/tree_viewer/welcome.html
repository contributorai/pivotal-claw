Technical details

Everything underneath stays simple.

What files make up a board?

Five Markdown files — icebox.md, todo.md, doing.md, done.md, and epics.md — plus small JSON sidecars for notes and sessions. A story is one line: - Add a dark-mode toggle #board t:boar002. Stable IDs, hashtag epics, and a portfolio view that groups epics into initiatives.

What can an agent do?

Read the board, add stories, attach notes, move stories between lanes, and follow a built-in onboarding-tour script — all over a plain HTTP API documented in skill.md.

What's different on your laptop?

Run Pivotal locally and it does more than the demo: it also launches and tracks Claude/Codex work sessions per story, so the board becomes the control panel for your agents' work. Session launching is disabled on this shared cloud demo.
